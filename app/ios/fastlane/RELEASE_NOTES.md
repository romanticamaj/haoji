「留著 KEEPLACE」外觀第 3 步：錄音、錄音檢視、確認匯入。

調整
• 錄音畫面：按鈕改成鼠尾草綠的圓鈕（麥克風圖示開始、方塊停止），旁邊是白色圓框的暫停鈕。錄音中只有「錄音中」旁的小橘點，不再有紅色。
• 音量光圈變得更淡；打開 iPhone 的「減少動態效果」時，光圈會保持不動。
• 沒有麥克風權限時，會清楚寫「沒有麥克風權限」，並有「前往設定」按鈕。
• 錄音被電話打斷時，提示改成「錄音被中斷了／已經錄下的部分都保存好了。要接著錄嗎？」。
• 錄音檢視：大標題「錄好了，先聽聽看」，「生成逐字稿」固定在下方，「稍後再說」和「捨棄」在它下面。捨棄的確認會說明錄音會從手機移除。
• 確認匯入（選多個檔案時）：每個檔案是細框線卡片，勾選框改綠色；拖曳時卡片外框變綠，不再有陰影。
• 錯誤訊息改成白話，不再顯示英文的系統訊息。

請重點測試
1. 錄音：開始、暫停、繼續、停止都正常；錄音中只有小橘點，沒有紅色。
2. 錄音中打電話進來（或用其他 App 搶走麥克風），回來看到「錄音被中斷了」，按「繼續」能接著錄，錄音沒有不見。
3. 在「設定 → 隱私權 → 麥克風」關掉好記，再按錄音，應出現「沒有麥克風權限」和「前往設定」。
4. 開啟「設定 → 輔助使用 → 動態效果 → 減少動態效果」後錄音，光圈應保持不動。
5. 匯入 3 個以上音檔，確認畫面可以勾選、試聽、拖曳調整順序；合併後順序正確。
