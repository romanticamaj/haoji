【嚴重修正】錄音中接到電話後，先前錄的內容被洗掉

回報：錄音中電話進來 → 秒數停住 → 按繼續 → 前面錄的全部不見。

原因是「第幾段」記在記憶體、檔案存在磁碟，兩者可能不同步：通話仍佔著麥克風時
續錄會失敗，畫面掉回待機狀態；再按一次錄音鍵就會把段落清單重設成空的，於是新錄
音用回索引 0，直接覆蓋掉先前那段。

現在「第幾段」一律由磁碟決定，任何情況都不會重用既有索引；被遺忘的段落也會被撿
回來，不會變成孤兒。

同批一併修掉的相關風險：
• 續錄失敗時停在「已暫停」而不是待機，繼續提示不會消失
• 通話後續錄若無法恢復，會自動改開新的一段，而不是假裝在錄（原本錄不到聲音）
• 匯入的 mp3／caf 等格式不再被誤判為「不是段落」而從會議中消失
• 合併音檔改為「先寫入、後刪除」，中途失敗不會兩頭落空
• 啟動時的殘檔回收不會覆蓋既有段落
• 中斷收尾的段落長度不再被記成 0

【請測這個】
1. 開始錄音 → 講幾句
2. 用另一支手機打進來（或請人打給你）
3. 掛掉後回到 App，按「繼續」
   → 先前錄的內容必須還在
4. 停止 → 播放，確認通話前後兩段都完整

【也請順便試】
• 通話中直接按停止 → 先前的內容也要在
• 錄音中暫停、講電話、掛掉後再按繼續

【前幾版修的，仍未在真機驗過】
• 補錄後「重新生成逐字稿」不會一進去就跳出
• 匯入多個中文檔名音檔 → 確認畫面可試聽、可拖曳排序
